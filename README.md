# ✦ Literati ✦

> *A Curated Workspace for the Poetic Mind*

**Literati** is an interactive web workspace designed to combat writer's block by serving procedural, infinitely varied writing prompts. Built with an enchanted dark forest aesthetic featuring swaying lanterns, glowing fireflies, and rich typography, it offers a tranquil, distraction-free environment for poets, creative writers, and literature enthusiasts.

---

## Features

* **Procedural Prompt Engine:** Generates thousands of unique, non-repeating poetic scenarios across four distinct themes (*Nature & Wilderness, Dark Academia, Melancholy & Nostalgia, Romanticism*).
* **The Prompt Jar 🏺:** Save and pin your favorite generated prompts locally to build a personal repository of inspiration for future writing sessions.
* **Drafts & Ideas Pad:** An integrated, auto-saving notepad to capture stanzas, line ideas, or full poems in real time without leaving the workspace.
* **Lexicon Lookup 📖:** An ultra-fast hybrid dictionary and synonym finder featuring instant offline fallbacks and API integration to discover poetic vocabulary on the fly.
* **Atmospheric UI:** Immersive CSS visual features including floating firefly animations, gently swaying lanterns, and a dark mossy color palette.

---

## Tech Stack

* **Frontend:** HTML5, Modern CSS3 (Flexbox/Grid, CSS Keyframe Animations, CSS Custom Properties)
* **Scripting:** Vanilla JavaScript (ES6+, LocalStorage API, Fetch API, AbortController, Procedural Grammar Engine)
* **APIs:** Datamuse API (Lexicon Lookup)
